# hivelight-site

The landing page for **[Hive Light](https://github.com/fr1j0/hive-light)** — a native
macOS menu-bar traffic light for your Claude Code sessions.

**Live:** https://fr1j0.github.io/hivelight-site/

One self-contained `index.html`, no build step, served by GitHub Pages.

## Contributing

This repository does not accept contributions — it exists to version and serve the
site. For the app itself (where contributions are welcome), head to
[fr1j0/hive-light](https://github.com/fr1j0/hive-light).
